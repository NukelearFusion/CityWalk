# CityWalk — подготовка к показу

## Запуск (≈ 2 минуты)

1. Запустить **Docker Desktop** и дождаться статуса «Running».
2. Сервер:

   ```bash
   cd server
   npm run db:up       # PostgreSQL в Docker
   npm run db:migrate  # только при первом запуске на новом компьютере
   npm run db:seed     # только при первом запуске: 4 города, 8 маршрутов
   npm run dev         # API на http://localhost:4000
   ```

   Проверка: http://localhost:4000/health → `{"status":"ok"}`.

3. Приложение (во втором терминале):

   ```bash
   cd client
   npm start
   ```

   - **Телефон:** Expo Go **для SDK 57** (https://expo.dev/go), та же Wi-Fi сеть, отсканировать QR
     или ввести адрес `exp://<IP компьютера>:8081`.
   - **Компьютер:** клавиша `w` в терминале или http://localhost:8081 (карта в браузере не показывается).
   - Файл `client/.env` задаёт адрес API: `EXPO_PUBLIC_API_URL=http://<IP компьютера>:4000/api/v1`
     (IP — команда `ipconfig`, адаптер Wi-Fi). После изменения: `npx expo start -c`.
     Без `.env` приложение работает на встроенных тестовых данных — запасной вариант.

## Сценарий показа

1. Главный экран — рекомендуемые маршруты (4.1.1).
2. «Города» → Poznań → 5 маршрутов разных категорий (4.1.14, 4.1.15, 4.1.2).
3. Маршрут «Od Starego Rynku na Ostrów Tumski»: описание, категория, дистанция, время,
   остановки, карта, стартовая точка (4.1.3–4.1.10, 4.1.16, 4.1.18–4.1.20).
4. «Поиск»: ввести `poznan` или `krakow` без диакритики, применить фильтры по времени
   и дистанции (4.1.11–4.1.13).
5. API в браузере:
   - http://localhost:4000/api/v1/cities
   - http://localhost:4000/api/v1/routes?city=poznan&maxDurationMinutes=60
   - http://localhost:4000/api/v1/favorites → 401 без входа (разграничение прав).
6. Качество: в папке `server` — `npm test`, `npm run lint`, `npm run typecheck`.

## Возможные проблемы

- **Docker не запущен** → API не стартует (нет подключения к БД).
- **Телефон пишет «incompatible with this version of Expo Go»** → установить Expo Go для SDK 57.
- **Телефон не видит компьютер** → другой Wi-Fi, изоляция клиентов в сети или сменился IP
  (обновить `client/.env`). Запасной вариант — удалить `.env` и показывать на тестовых данных.
- **`npm run build` с ошибкой EPERM** → API ещё запущен и держит файл Prisma; остановить и повторить.
