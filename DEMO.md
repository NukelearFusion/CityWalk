# CityWalk — подготовка к показу

```
Diplomka/
├── Maps/         # backend: REST API (Express 5, Prisma, PostgreSQL)
├── mapsmobile/   # мобильное приложение (Expo / React Native)
└── docs/         # требования 4.1.1–4.1.35 и диаграмма прецедентов
```

## Запуск (≈ 2 минуты)

1. Запустить **Docker Desktop** и дождаться статуса «Running».
2. Backend:

   ```bash
   cd Maps
   npm run db:up       # PostgreSQL в Docker
   npm run db:migrate  # при первом запуске
   npm run db:seed     # при первом запуске: 3 города, 3 маршрута, админ
   npm run dev         # API на http://localhost:4000
   ```

   Проверка: открыть http://localhost:4000/health — должно быть `{"status":"ok"}`.

3. Мобильное приложение (во втором терминале):

   ```bash
   cd mapsmobile
   npm start           # QR-код → Expo Go на телефоне (та же Wi-Fi сеть)
   ```

   - **Без `.env`** приложение работает на встроенных тестовых данных (5 маршрутов) — самый надёжный вариант для показа.
   - **С реальным API:** создать `mapsmobile/.env` со строкой
     `EXPO_PUBLIC_API_URL=http://<IP компьютера>:4000/api/v1` (узнать IP: `ipconfig`) и запустить `npx expo start -c`.

## Сценарий показа

1. Главный экран — рекомендуемые маршруты (4.1.1).
2. Вкладка «Города» → Kraków → список маршрутов города (4.1.14, 4.1.15, 4.1.2).
3. Маршрут «Droga Królewska»: описание, категория, дистанция, время, остановки, карта, стартовая точка (4.1.3–4.1.10, 4.1.16, 4.1.18–4.1.20).
4. Вкладка «Поиск»: ввести `krakow` (без диакритики — найдёт «Kraków»), применить фильтры по времени и дистанции (4.1.11–4.1.13).
5. Backend в браузере или Postman:
   - http://localhost:4000/api/v1/cities
   - http://localhost:4000/api/v1/routes?q=wawel&maxDurationMinutes=120
   - `/api/v1/favorites` без входа → 401; запрос обычного пользователя к `/api/v1/admin/cities` → 403 — показывает разграничение прав.
6. Показать качество: `npm test`, `npm run lint`, `npm run typecheck` в `Maps`.

## Возможные проблемы на показе

- **Docker не запущен** → API падает при старте с ошибкой подключения к БД.
- **Телефон не видит API** → в `.env` указан `localhost` вместо IP компьютера, или брандмауэр Windows блокирует порт 4000. Запасной вариант — удалить `.env` и показывать на тестовых данных.
- **Вход администратора** требует кода из e-mail: без SMTP код печатается в консоли API. При первом входе сид-аккаунт обязан сменить пароль.
- **`npm run build` с ошибкой EPERM** → API ещё запущен и держит файл Prisma; остановить сервер и повторить.
